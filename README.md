# LIBS 煤炭发热量预测 — Baseline 教程

**任务**: 通过激光诱导击穿光谱（LIBS）预测煤炭发热量（kcal/kg）  
**评估**: 线上 RMSE（越低越好）  
**当前版本**: V8  默认 Contrastive-32 + RidgeCV，CV-RMSE ≈ 184；可选 PCA（详见下方说明）

> 本项目基于 [Datawhale](https://datawhale.cn) 教学赛项目改造，赛题来源：[AI 实战训练营 — LIBS 煤炭发热量预测](https://ailc.datawhale.cn/hall/group/100000937)

## 方法说明

### 核心思路: 两阶段回归

```
LIBS 光谱 (7305维, 196-813nm)
        │
        ▼  Stage 1: 光谱 → 辅助指标
   全水分 / 灰分 / 氢 / 硫  (OOF 预测)
        │
        ▼  Stage 2: [光谱特征 + 辅助指标] → 发热量
   发热量 Q (kcal/kg)
```

**为什么两阶段?**  
辅助指标（灰分↑ → 发热量↓，氢↑ → 发热量↑）与目标强相关，
先预测辅助指标相当于把物理先验注入模型。

### 特征设计

| 特征 | 维度 | 关键思路 |
|---|---|---|
| 特征提取（默认 Contrastive-32） | 32 | 对比学习编码器，替代 PCA（config 可切 PCA） |
| 统计特征 | 17 | 偏度/峰度/熵反映谱线丰富程度 |
| 谱线积分 | 11×2 | C(247.86nm)/H(656.3nm)/灰分元素 |
| 物理比值 | 4 | 可燃/灰分、H/C 等 |

### 防过拟合策略

1. **正则化**: Ridge，`ALPHAS = [1.0, 10.0, 50.0, 100.0, 500.0, 1000.0, 5000.0, 10000.0]`（候选最小 1.0）。**α<1 必过拟合**——本项目训练/测试分布偏移下，低正则化让 Ridge 过拟合训练批次模式；线上单调劣化：α≈1.0→241.86, 0.3→248.33, 1e-3→255.62（见实验 #79/#80/#81）。任何 α 调参必须以线上验证为最终判据，不得下探至 1 以下。
2. **GroupKFold CV**: 以批次为单位分组，防止同批次光谱泄露
3. **均值收缩**: 批次数 ≤ 10 时，预测值向煤种均值收缩
4. **OOF**: Stage2 输入的辅助指标来自 Out-of-Fold 预测

### 全局 CV-RMSE 计算（v2026-07-15 更新）

采用**测试加权 pooled** 方式对齐线上评测：

1. **煤种内**: 汇集所有 OOF 批次预测值算 pooled RMSE（而非平均各 fold 的 RMSE）
2. **跨煤种**: 按各煤种**测试集批次数**平方加权再开方（而非按训练集批次数加权平均）

```
global = sqrt( Σ(rmse_i² × n_test_i) / Σ(n_test_i) )
```

这样每个测试批次等权，与线上评分 `sqrt(mean(true-pred)²)` 一致。
基线测试加权 CV-RMSE ≈ 188（线上 278），与线上分数变化方向协同性优于旧方法。

## 调参建议

修改 `config.py` 中的参数:

```python
# 特征提取方式: "contrastive_32" / "pca" / "ae_16" / "mae_16" 等
FEATURE_EXTRACTOR = "contrastive_32"

# PCA 最大保留维数（FEATURE_EXTRACTOR="pca" 时生效）
N_PCA_MAX = 30

# Ridge 正则化候选值
ALPHAS = [1.0, 10.0, 50.0, 100.0, 500.0, 1000.0, 5000.0, 10000.0]

# 均值收缩阈值（批次数 ≤ 此值时生效）
SMALL_BATCH_THRESHOLD = 10
```

## 进一步优化方向

> 采纳判据说明：本项目反复验证「CV 越低 ≠ 线上越好」，离线 CV 与线上系统性背离。新方向以**线上验证**为最终判据，`eval_proxy.py` 离线代理（与线上秩相关 +0.80）仅作提交前门控。

**候选方向（尚未证伪，按优先级）：**

- [ ] **提交前门控流程化**：把 `python eval_proxy.py --analyze` 纳入提交前检查，proxy_lobo 较当前最优明显上升则不提交（能拦住降 α / 换 PCA 类倒退）。
- [ ] **重要性加权 CV（谨慎）**：用 adv 分类器给「更像测试集」的批次加权评估；全局 AUC≈0.5 空间有限，仅偏移大的煤种（中马矿 AUC≈0.62）可能有效。
- [ ] **增加线上锚点标定 proxy**：当前一致性仅 4 锚点支撑，多提交已知配置可提升 proxy 可信度与细粒度。
- [ ] 多版本集成（对已验证强正则模型做 seed/子集 bagging；注意 WT-A 已证降方差对绝对水平帮助有限）

> **已排除的方向（经实验验证）：** （注：以下 CV-RMSE 采用当时的 per-fold 平均法计算，与当前测试加权 pooled 值不可直接比较，但线上分数和实验结论不变）
> - 树模型（LGBM/XGBoost）替换 RidgeCV — 线上 283.89 vs RidgeCV 278.50，小样本下非线性能力有害。详见实验 #5~#15。
> - 预测值异常值剔除后取中位数 — CV↓1.12 但线上↑6.3，CV乐观偏差。详见实验 #17。
> - **（现状：已作为默认方案）对比学习(Contrastive-32) 替换 PCA → 线上 241.86，↓36.64 (13.2%)** — AE/MAE/VAE/1D-CNN 四种方案全面退化（隐变量维度关联与 RidgeCV 独立贡献假设冲突），但对比学习的隐式正则化效果足以超越 PCA。默认 `python train.py` 即使用此方案。详见实验 2026-07-16。
> - **光谱级数据增强** — 6 种策略（批次内 Mixup/高斯噪声/幅值抖动/组合/折内跨批次 Mixup/物理散粒噪声）50+ 参数组合全部不优于基线。小样本定向 Mixup 虽获 CV 改善 164.98，但线上 290.29 证伪。RidgeCV 正则化已饱和，合成数据不带来新信息。详见实验 #26~#74。
> - **Boltzmann 图等离子体温度** — 新增 6 维特征（Fe I 谱线温度 + Ca II/Ca I、Hα/C、Si/Mg 比值），CV-RMSE 184.65→180.13↓4.52，但线上 241.86→243.99↑2.13。CV 改善不泛化到线上，与异常值剔除等方向相同的「CV 乐观偏差」模式。详见实验 #77。
> - **批次内光谱异常检测** — 每批次内谱形/强度/C-H 比 3 准则剔除 14%~23% 光谱，CV↓11.67 但线上 241.86→274.18↑32.32。CV 乐观偏差：剔除的是真实分布必要变异。详见实验 #78。
> - **FLAML AutoML 自动化架构搜索** — 以 FLAML 替换两阶段 RidgeCV（自动选 lgbm/rf/xgboost 等），CV-RMSE 184→231 显著退化；小样本煤种（86~360 条光谱）下 AutoML 选中低正则化复杂模型过拟合。Auto-sklearn 因 Windows+Py3.11 不兼容未采用（改用跨平台 FLAML 仍不敌强正则 RidgeCV）。详见实验 #83（汇总表 #14）。
>
> **本轮 5-worktree 并行探索（2026-07-29，全部未超线上最优 241.86，详见 EXPERIMENT_LOG.md 实验 #84~#88）：**
> - **WT-B 双管线集成（PCA+对比学习-32 批次预测平均）** — CV 180.66（全场离线最优）但线上 260.99↑19.14。典型 CV 假阳性。实验 #84。
> - **WT-D transductive（train+test 无标签光谱纳入对比预训练）** — CV 192.04，线上 271.29↑29.43；未带来增益反劣化，且有接触测试集合规风险。实验 #85。
> - **WT-A 多种子集成（8 编码器）** — CV 193.36；验证了集成能降编码器方差（单编码器 203.93±17.92 → 193.36），但绝对水平不及最优，未提交。实验 #86。
> - **WT-C EPO 批次噪声正交化** — 扫描 k∈{0,1,2,3,5}，最优 k=0（等于不做），EPO 无增益，排除。实验 #87。
> - **WT-E 直接预测（去 Stage1）** — CV 275.62，全面劣化，确认两阶段 Stacking 不可省。实验 #88。
>
> **方法论工具（非模型方向）：** `eval_proxy.py` 离线代理评估框架 — proxy_lobo 与线上 Spearman +0.80（旧 CV 为 −0.80），可作提交前门控但不替代线上。详见「方法论 — 2026-07-29」。
>
> **组合方向离线评估（eval_combos.py，2026-07-29，详见实验 #89）— 以下经 8+6 组合 proxy_lobo 评估证伪：**
> - **保守收缩校准（全局 w<1）** — 诚实 LOBO 下 w 从 1.0 单调下探 proxy 单调变差（1.0→161.70, 0.9→175.67, 0.7→206.77），收缩只增偏差；现有「仅小批次 OOF 调 w」保持不变。
> - **辅助指标质量筛选（剔除 OOF R²<0 的辅助列）** — 4 个辅助指标 Stage1 OOF R² **全为负**（光谱预测辅助指标比直接用均值还差），但作为 Stage2 特征仍显著有用，剔除后 proxy 崩到 254.27。**关键洞见：两阶段有效不是因辅助指标预测准，而是 OOF 辅助值作为工程特征；辅助列须全留。**
> - **跨煤种 Stage1 共享（辅助模型联合训练）** — 5 煤种发热量分布差异大，混训引入跨煤种偏置，proxy 崩到 297.70，远劣于分煤种独立训练。
> - **稳健批次聚合 trimmed@10（去上下10%取均值）** — proxy_lobo 161.70→157.00（↓4.70，离线最优），但**线上 247.05327 ↑5.19（较最优 241.86 更差）**。又一例 proxy 假阳性：proxy 分不开安全区内聚合方式的 ~3% 细粒度差异。median 仍为最优聚合，mean 变体（proxy 159.81）同属该族不再提交。详见实验 #89。
