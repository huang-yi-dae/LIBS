# P02 — LIBS Methods Primer (Nature Reviews Methods Primers, 2025)
**来源**: https://www.nature.com/articles/s43586-025-00388-w （开放获取）
**类型**: 方法学总览（非特定煤应用，但普适指导意义强）

## 推荐预处理
- **基线/背景校正**：多项式拟合；无模型算法（Ref 027-029）；小波变换背景去除（Ref 030/037/038）；地质样品基线方法对比（Ref 036）。
- **平滑/去噪**：小波阈值去噪（Ref 041/045）；平稳小波自适应抑噪（Ref 038）。
- **重叠峰分辨**：曲线拟合（Ref 048/049）；连续小波自动拟合（Ref 050）；Richardson–Lucy 解卷积（Fig.3）。
- **归一化（抑矩阵效应）**：自适应加权归一化（Ref 072）；多线内标校准（Ref 177）。

## 矩阵效应 / 信号波动
- 归一化、CF-LIBS（免标定 LIBS）+ 单点校准（Ref 071/085）、内参比线自动选取（Ref 176）。
- 双脉冲增强等离子体（Ref 179-181）、气氛控制。

## 建模方法
- **PLS**：与煤碳杂交（Ref 032）；PLS+ANN 自动预处理（Ref 039）。
- **ANN**：CF-LIBS/ANN 杂交（Ref 084）；前馈 ANN（Ref 039）。
- **PCA & 变量选择**：递归特征消除+小波（Ref 046）；快速变量选择（Ref 047）。
- **CF-LIBS**（免标定）：Ref 074/075/057。

## 防过拟合最佳实践
- 独立测试集；降维（PCA/变量选择）后再建模；交叉验证。

## 常见陷阱
- 矩阵效应/分馏未处理 → 强度非代表性。
- 等离子体非 LTE 仍套用假设。
- 重叠峰忽略（低分辨率谱需解卷积）。
- 基线误建模（多项式/算法选错偏置峰）。
- ML 变量过多且无验证 → 过拟合。

## 对本项目的可迁移点
- 把**小波去噪 + AirPLS/多项式基线 + 内标归一化**纳入 `features.py` 候选流程。
- 强调**独立测试集 + 降维防过拟合**——印证我们 GroupKFold + 两阶段收缩（`model.py`）的方向。
- 重叠峰解卷积（连续小波）可能提升 KEY_LINES 峰面积精度。
