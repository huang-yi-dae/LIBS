# P05 — Synchronized LIBS-NIRS with Distance Correction (Talanta, 2026)
**来源**: https://www.sciencedirect.com/science/article/pii/S0039914025015425
**目标变量**: 灰分/水分/发热量/挥发分/固定碳/全硫（含发热量）

## 问题
- 传送带动态煤层厚度变化 → 检测距离（DD）波动 → 谱质下降。

## 校正方法（软件，无硬件对焦）
1. **距离识别**：用 NIRS 谱经 RF 分类识别 DD。
2. **有效性筛选**：用特征峰**标准差 SD** 剔除无效谱。
3. **谱重建**：PCA + RF + SHAP 混合，将带 DD 标签的有效谱重建为参考距离理想谱。

## 融合
- 同步 LIBS+NIRS 同点采集（保证同源）；校正后**十进制缩放（decimal scaling）归一化融合**。

## 结果（校正后 AAE）
| 参数 | AAE |
|------|-----|
| 灰分 | 0.405% |
| 水分 | 0.143% |
| 发热量 | 0.258 MJ/kg |
| 挥发分 | 0.117% |

## 对纯 LIBS 的可迁移点
- **SD 有效性筛选**：用 LIBS 特征峰标准差剔除低质谱（off-distance / 异常）。
- **PCA+RF+SHAP 谱重建**：与模态无关，可用于重建理想 LIBS 谱（类比我们的 AE/MAE 重建）。
- 检测距离若能在纯 LIBS 下由光斑对称性估计，则整套校正可迁移。
- **含义**：我们当前 `data.py` 是否做了谱质量筛选？若没有，SD/离群筛选是直接可加的预处理层。

## 注意
- NIRS 专用于 DD 识别与水分；纯 LIBS 缺水分分子信息，水分预测会退化（与本项目目标无关，可忽略）。
