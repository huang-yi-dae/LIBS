# P06 — Review: LIBS for Coal Analysis 2011–2020 (Fuel, 2021)
**来源**: https://www.sciencedirect.com/science/article/pii/S0165993621001801 （付费墙，仅摘要级）
**综述范围**: LIBS 煤分析的属性、预处理、建模、挑战。

## 已成功预测的属性
- 元素：C/H/O/N/S/Si/Na/Mg/Al/K/Ca/Cr/Mn/Fe/Cu/Hg/Zn。
- 煤阶、燃烧效率、污染监测、**灰分、挥发分、发热量**、未燃碳。

## 主导预处理与建模（从引用推断）
- 预处理：数据滤波、数据变换、**变量选择**（去随机/寄生误差）。
- 样品预处理：压样力、粘结剂、钠吸附剂（减粒度/表面/异质效应）。
- 建模：PLS（多篇）、KELM/ELM、小波+PLS 杂交、机器学习（变量选择辅助）。
- 联用系统：LIBS+NIRS、LIBS+FTIR、LIBS+LA-ICP-TOF-MS。

## 关键挑战
- **异质性/不均匀材料** → 样品制备 + 数据预处理缓解。
- 系统/随机/寄生误差 → 滤波、变换、变量选择。
- 实时需求 → 在线 LIBS 仪器。

## 深度学习 / 表示学习 / 迁移学习
- 综述（2011–2020）**未提及**深度学习/表示学习/迁移学习；最近邻为浅层 KELM/ELM。
- 印证：**LIBS+深度表示学习（AE/MAE/对比）正是较新且本项目已布局的方向**，有前沿空间。

## 对本项目的可迁移点
- 变量选择 + 滤波 + 变换是共识基线，应成为 `features.py` 标准组件。
- 联用系统思路 → 若未来有多模态数据可融合（本项目暂无 NIRS）。
- 确认我们的深度 encoder 方向在综述时间窗之外，属较新探索。
