# P01 — Coal Quality Analysis Based on LIBS + Machine Learning (MDPI, 2025)
**来源**: https://www.mdpi.com/2813-446X/3/4/32 （开放获取）
**目标变量**: 灰分 Aad、碳含量 Cd、硫含量 Stad（**未涉及发热量**）

## 采集与预处理
- 系统：Nd:YAG 1064nm, 8ns, ≤200mJ；Avantes 光谱仪 181–769nm, ~0.15nm 分辨率。
- 每样品 5×5 点 × 5 发 = 125 条谱，平均成 1×4094 向量。
- 预处理流程：
  1. 背景去除 `I = Iraw − Ibackground`（本实验背景≈0）。
  2. 离群剔除：与均值偏差平方和 > `1.1 × (1/150 ΣAi)` 的谱丢弃。
  3. **归一化**：Min–Max `(I−Imin)/(Imax−Imin)`。
  4. **基线校正**：滑动窗口最小值相减，窗口=16（经验选定）。
- 无显式平滑滤波。

## 特征工程
- **峰提取**：峰阈=0.01，非峰置零；保留特征波长（灰：K/Ti/Zn/Na/Si/Ca/Fe/CN 等 24 条线；碳：192.8/247.89/283.82/589.11nm；硫：415.24/550.24/563.58nm）。
- **PCA**：对峰数据降维，剔除可忽略变量。
- **VIP**（变量投影重要性）：用于灰分变量重组。

## 模型
- 核心：**PLSR**，潜变量数经 CV 选优（灰5/硫6/碳5，最终统一 L=5）。
- 组合：PLSR + PCA。无深度学习/自编码器/对比学习。

## 结果（测试集 R²）
| 目标 | 方法 | R² | RMSEP |
|------|------|-----|-------|
| 灰分 | 全谱 PLSR | 0.92 | 1.01 |
| 碳 | 峰+PCA-PLSR | 0.86 | 1.19 |
| 硫 | 峰+PCA-PLSR | 0.90 | 0.003 |

**结论**：PCA+峰特征对碳/硫更优；全谱 PLSR 对灰分略优。无数据增强/迁移学习。

## 对本项目的可迁移点
- 滑动窗口最小值基线校正（window=16）可对比我们当前 baseline 方法。
- 峰提取 + PCA + VIP 的特征流程与 `features.py` 思路一致，可借鉴 VIP 做变量筛选。
- Min–Max 归一化是简单基线。
