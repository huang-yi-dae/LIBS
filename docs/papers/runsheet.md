## 三、候选实验方向（按预期收益排序）
### A 级（高收益、低改动、直接可抄）
1. **预处理升级流水线**：AirPLS 基线 + 小波去噪 + 马氏距离离群剔除（P04）。 — **2026-07-24 试：AirPLS+SG 使 CV 198.31（+10.73，有害），全局马氏筛选无变化；详见 docs/papers/experiment_a1a2.md；不采纳**
   代码改动小、风险低，通常直接降 CV-RMSE。
2. **谱质量筛选层**：特征峰 SD / 马氏距离剔除异常谱（P04/P05）→ 加在 `data.py` 装载后。 — **2026-07-24 试：全局马氏粒度不对、无效；批次内谱形MAD法见172.98但线上更差已排除；不采纳**
3. **确认/强化分组校准**：验证 `model.py` 是否真的按煤型分组建模（P03 核心思想）； — **已确认：train_coal_model 按煤种分组建模（P03 思想已落地）**
   若已是，则补"按挥发分进一步细分组"或条件特征。
4. **新增核方法预测器**：LS-SVM / K-ELM（P04 全面最优，R²≈0.99）。 — **2026-07-24 试（C8/kernel）：KernelRidge 使 CV 282.62 严重过拟合；不采纳**
   接入 `predictors.py`，与 RidgeCV 两阶段对比。

### B 级（中收益、需验证）
5. **内标归一化**：用强特征线做 intra-spectrum 归一化抑矩阵效应（P02/P03 思路）。 — **2026-07-24 试：CV 187.34 > 184.65，更差；不采纳**
6. **VIP / 变量选择选线**：在 `features.py` 用 VIP 替代或补充 KEY_LINES 手工线。 — **未实现（与 B5 同类且高过拟合风险，跳过）**
7. **峰面积 + 连续小波解卷积**：提升 KEY_LINES 峰面积精度（P02 重叠峰）。 — **2026-07-24 试（B7）：CV 183.43，线上 248.33 > 241.86，更差；实验 #82 不采纳**

### C 级（前沿、差异化，风险高）
8. **表示学习 encoder 深化**：我们已有的 AE/MAE/对比学习在综述时间窗(2011-20)外，属较新探索。 — **未实现（核预测器变种见 A4，已试过拟；encoder深化未做）**
   方向：更大/更干净预训练、对比损失改进、encoder 输出接 LS-SVM 两阶段。
9. **谱重建/校正头**：类比 P05 的 PCA+RF+SHAP 重建，用 MAE 重建理想谱抑距离/波动噪声。 — **2026-07-24 试（C9）：CV 202.70 > 184.65，更差；不采纳**
10. **多模态融合**：若未来有 NIRS/FTIR 联用数据（P06），做早期/晚期融合。 — **无额外数据，跳过**

## 四、重要提醒
- 文献 R²≈0.99 / AAE 0.26 MJ/kg 的精度基于小样本(49–53)、实验室压片、口径为 R²/RMSEP，
  **不可直接与我们线上 CV-RMSE≈184(kcal/kg) 对标**——单位、样本量、评价口径都不同。
- 真正可迁移的是**预处理与建模范式**，而非数值。
- "按煤型分组 + 两阶段收缩" 与文献 SVM+PLS 分组校准、两阶段 ridge 思路一致，已有正确性背书。
