# P04 — Advanced Multi-Parameter Prediction of Coal Quality Using LIBS + ML (ACS Omega, 2025)
**来源**: https://pubs.acs.org/doi/abs/10.1021/acsomega.5c03962
**目标变量**: C_ad, A_ad, V_ad, S_t,ad, **Q_gr,ad（发热量 15.07–24.78 MJ/kg）** —— 含发热量

## 预处理（三步，强可迁移）
1. **离群剔除**：马氏距离（多元正态），阈值剔除末 100 点，保留 70% 数据。
2. **基线校正**：**AirPLS**（自适应迭代重加权惩罚最小二乘，无需人工/先验峰信息）。
3. **去噪**：**小波变换**（低信背比场景有效）。

## 模型对比（4 个，仅浅层，无深度学习/无特征选择）
- SVM (RBF, C=10, γ=0.01)
- RF (200 树, max_depth=20)
- K-ELM (高斯核, σ²=1.0, C=100)
- **LS-SVM** (RBF, γ=0.01, λ=1e-4) —— **全面最优**

## 验证
- 70/30 训练/测试；10 折 CV。指标：R², RMSEP, MAE, MRE。49 样 × 200 空间点。

## 结果（LS-SVM 最佳）
| 参数 | R² | RMSEP | MRE |
|------|-----|-------|-----|
| C_ad | 0.9940 | 0.64% | 1.17% |
| A_ad | 0.9940 | 0.89% | 4.05% |
| V_ad | 0.9929 | 0.53% | 2.30% |
| S_t,ad | 0.9928 | 0.06% | 10.49% |
| **Q_gr,ad** | **0.9942** | **0.26 MJ/kg** | 1.18% |

LS-SVM 全面胜出 SVM/RF/K-ELM；硫 MRE 最高（10.49%，谱线重叠+空间异质）。

## 对本项目的可迁移点（高价值）
- **AirPLS 基线校正** + **小波去噪** + **马氏距离离群剔除** 是可直接放进 `features.py` 的成熟流水线。
- **LS-SVM / K-ELM** 可作为 `predictors.py` 的新候选（当前有 RidgeCV/XGBoost/RF/GBR/MLP，缺核方法）。
- 本文 R²≈0.99 的精度远高于我们 CV-RMSE≈184 的水平——但样本量（49）和指标口径不同，需谨慎对标。
