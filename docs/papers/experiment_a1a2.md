# 实验报告：A1（AirPLS基线+去噪）+ A2（马氏距离谱质量筛选）

**分支/工作树**：`feat/a1-a2-preprocess`（已在 2026-07-24 清理时删除；本报告已并入主分支保留）
**日期**：2026-07-24
**方法学依据**：`runsheet.md` 中 P04（AirPLS + 小波 + 马氏距离）、P05（SD 有效性筛选）

## 1. 实验设计
- 所有改动通过 `config.py` 的环境变量开关隔离，主流程默认不变：
  - `LIBS_AIRPLS=1` / `LIBS_DENOISE=1`（A1）
  - `LIBS_SCREEN=1`（A2）
  - `LIBS_EXTRACTOR=pca`（用 PCA 路径做公平 A/B，避免对比学习编码器在预处理前后的不一致）
- 新增 `src/preprocess.py`：AirPLS（稀疏带状求解，避免稠密 O(N³)）、SG 去噪（小波等价、无新依赖）。
- `features.py`：在 `spectrum_features` 最前端应用 A1。
- `data.py`：在 `load_coal_spectra` 末尾按煤种做 A2 马氏距离筛选。

## 2. 结果（全局 CV-RMSE，kcal/kg，越小越好）
| 配置 | 全局 CV-RMSE | 相对 PCA 基线 |
|------|-------------:|--------------:|
| **PCA 基线（无 A1A2）** | **187.58** | — |
| A1（AirPLS + SG） | 198.31 | +10.73（更差） |
| A2（马氏筛选，conf=0.975） | 187.58 | 0.00（无变化） |
| A1 + A2 | 198.31 | +10.73（更差，由 A1 主导） |

> 参考：本仓库历史最佳离线 `对比学习-32` = 184.65；历史 `批次内光谱异常检测（谱形MAD+强度z+C/H比z）` = **172.98**（见 `output/experiment_log.csv`）。

## 3. 诊断（为什么是这样）
### A1 有害
- 当前 `features.py` 已做 `inten/total` 总和归一化消除激光能量波动；数据很可能已由仪器做了基线扣除。
- AirPLS 强制减去连续谱包络，反而把含矩阵/丰度信息的连续背景当噪声去掉，削弱了 Ridge 模型可利用的低频信息。
- SG 去噪（window=11）对窄发射峰略有平滑，降低谱线积分的判别力。
- **结论：在本数据上 AirPLS+SG 不应启用。**

### A2 几乎无作用（本次实现）
- 初次运行 A2 得到 187.58（与基线完全相同）→ 排查发现 `np.linalg.pinv(cov)` 因 43 维特征协方差病态触发 `SVD did not converge`，被 `except` 静默吞掉，筛选从未生效。
- 加脊项（1e-2·I）修复后，马氏距离被大幅压缩（d2_mean 由 ~42 降到 ~23），conf=0.975 阈值下仅剔除约 **12 条**谱（占总 944 的 1.3%），对 CV 无影响。
- 即便诊断显示全局放宽为 conf=0.85 也仅剔除约 15%，且全局马氏距离混合了不同批次，对“同批次异常谱”不敏感。

### 关键洞察：筛选的**粒度**比阈值更重要
- 仓库已有的 **批次内**异常检测（谱形 MAD + 强度 z + C/H 比 z）做到 **172.98**，比全部分支最佳还低 ~12 分。
- 说明：异常谱应相对于**同一批次（同真值）**判定，而非全煤种全局马氏距离。全局马氏距离分布太“正常”，几乎剔不出东西。

## 4. 建议的下一步（按优先级）
1. **不要启用 A1（AirPLS/SG）**——本实验证明有害。
2. **A2 采用批次内检测器**：直接复用/扩展仓库已有的 `批次内光谱异常检测（谱形MAD+强度z+C/H比z）`，并接到 contrastive-32 路径上复现/超越 172.98。这是已验证的正确方向。
3. 若坚持做全局马氏筛选：应改为**逐批次内**计算马氏距离（或 MAD/分位数），而非全煤种混合；这样才可能复现 172.98 量级的提升。
4. 预处理方向可改试**内标归一化**（选强稳谱线做 ratio，对应 P02/P03 矩阵效应抑制），而非基线扣除。
